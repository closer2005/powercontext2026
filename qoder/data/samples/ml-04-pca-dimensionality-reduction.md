## 推导主线
1. 中心化：每列减均值。
2. 求协方差矩阵 `C = XᵀX / (n-1)`，它对称半正定。
3. 对 C 做特征值分解，特征值 λᵢ 就是该主成分方向上的方差。
4. 取最大的 k 个特征值对应的特征向量，投影得到 k 维表示。

## 实践要点
- 一定要先标准化再 PCA，否则量纲大的特征会主导方差。
- 方差解释率 = 前 k 个 λ 之和 / 所有 λ 之和，通常选到 90% 或 95%。
- 特征值接近 0 说明该方向几乎没有信息，可以丢弃。
- PCA 是线性方法，非线性结构用 t-SNE、UMAP 观察，但只用于可视化。

## 和 SVD 的关系
对 X 做 SVD 得 `X = UΣVᵀ`，右奇异向量就是主成分方向，奇异值平方与特征值成正比；sklearn 内部用 SVD 实现，数值更稳。

## 坑
把 PCA 当预处理时，必须在训练集上 fit、测试集上 transform，否则等于把测试集信息漏进训练，属于典型数据泄漏。
