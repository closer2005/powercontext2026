## 数据集划分
- train / val / test 三份：val 用来调参和 early stopping，test 只在最后跑一次。
- 小数据用 5 折或 10 折交叉验证，分类任务用分层抽样保持类别比例。
- 时间序列不能随机打乱，要按时间切分，否则未来信息漏进训练。

## 指标怎么选
- 类别均衡看 accuracy；不均衡看 precision / recall / F1。
- 排序场景看 AUC / NDCG；回归看 MAE / RMSE，RMSE 对大误差更敏感。
- 指标要写清平均方式（macro / micro / weighted），否则数字没有可比性。

## 对照实验与泄漏
- 报结果至少给 baseline、改进版两组；同一数据切分、同一随机种子，才叫对照实验。
- 常见泄漏：先对全量数据做标准化再划分、用测试集标签做特征、按样本重复采样后再划分。
- 我在实验记录里固定 seed=42，并把数据版本、依赖版本写进配置文件，否则结果没法复现。
